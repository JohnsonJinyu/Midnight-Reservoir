本地歌词文件夹（本地优先）
--------------------------------
★ 推荐做法：不用手放文件，直接跑同步器
   node tools\sync-lyrics.js            （或双击项目根目录的「同步歌词.bat」）
   它会把 QQ 音乐缓存里「你实际在听的版本」的歌词解密成 .lrc 放进本文件夹，
   同时生成 _index.json（带歌手和时长，用来精确挑选，同名不同曲不会串）。
   边听边补：node tools\sync-lyrics.js --watch

1) 也可以手放 LRC，文件名「歌名.lrc」「歌名 - 歌手.lrc」「歌手 - 歌名.lrc」都认，
   歌名带括号后缀的会自动再去掉括号试一次。
2) 取词顺序（前面的优先，任何一级命中就停）：
   ① 属性里填的「LRC 完整路径」
   ② _index.json 里按「歌名 + 歌手 + 时长」三重比对命中的那一条
   ③ 本文件夹里的同名文件
   ④ 属性里填的「歌词文件夹」（可写多个，用分号 ; 分隔）
   ⑤ 上一次成功匹配过的歌词缓存（同一首歌重播、甚至断网也能出词）
   ⑥ 联网匹配（网易云 → joox），带硬门槛：歌名对不上、歌手和时长也都不符的条目直接丢弃
3) 也可以在 Wallpaper Engine 属性里填「歌词文件夹」指向电脑上其它目录，
   例如 D:\Music\Lyrics;E:\网易云歌词
4) 支持 UTF-8 / GBK 编码，以及 LRC 内的 [offset:] 时间补偿；
   开头的「作词 : / 作曲 :」等制作信息默认跳过（属性里可关）。
5) 排查用：属性里打开「歌词诊断信息」，左下角会显示状态与来源，
   例如 LYRICS [ready] 40 行歌词已载入 · 本地缓存 · 玉芬 - 你像风一样出现
6) 没找到词不必重启壁纸：壁纸会自己隔一段时间重试（间隔逐次拉长）。

LRC 格式示例（纯文本，UTF-8 保存即可）
--------------------------------
[ti:歌名]
[ar:歌手]
[offset:0]
[00:00.00]第一句歌词
[00:05.20]第二句歌词
[00:11.75]第三句歌词
